**Propósito:** Este arquivo dita o sentido de existência da aplicação. Deve ser lido para contextualizar a interface com o usuário final e os administradores de comunidade, balizando decisões de UX e prioridades de negócio.

## Project Overview
Abertamente is a management system designed to coordinate community activities, register members (Comuneros), manage assets (agricultural and personal), and document official meetings and assemblies. The frontend application serves as the primary user interface for community organization administrators and users.
